# function-Python
This repository contains a Jupyter Notebook covering the fundamentals of functions and variables in Python. The notebook introduces reusable functions, function arguments, return values, variable scope, built-in functions, collections, and practical function-based exercises
## Notebook

Notebook: PY0101EN-3-3-Functions-jupyterlite.ipynb

## Learning Objectives

After completing this notebook, you will be able to:

- Understand functions and variables.
- Work with user-defined and pre-defined functions.
- Understand function parameters and arguments.
- Use return values from functions.
- Understand local and global variables.
- Work with variable scope.
- Use conditional statements and loops inside functions.
- Set default argument values.
- Work with collections and functions.
- Handle multiple function arguments.
## Topics Covered
### 1. Functions

The notebook introduces functions as reusable blocks of code that perform specific operations. It covers both pre-defined functions and user-defined functions, along with the basic structure and behavior of Python functions.

### 2. Function Parameters and Return Values

The notebook explains how functions receive inputs through parameters or arguments and how the return statement can be used to pass a result back to the caller.

It also covers what happens when a function does not explicitly return a value.

### 3. Variables

The notebook explains variables used within functions and distinguishes between local variables and global variables.

### 4. Functions and Code Reusability

Functions simplify programs by combining multiple instructions into a reusable unit. The same function can then be invoked with different input values, reducing repetitive code.
### 5. Pre-defined and Built-in Functions

The notebook introduces commonly used Python functions and explains how they can be applied to collections and other data.

Topics include:

- print()
- sum()
- len()
### 6. Conditions and Loops in Functions

The notebook demonstrates how functions can contain conditional logic and loops, allowing their behavior and returned values to depend on input conditions.

### 7. String Operations in Functions

The notebook explores string comparison and demonstrates how functions can be used to compare strings, check for matching text, and perform word-frequency operations.

### 8. Default Argument Values

The notebook explains how custom functions can define default values for arguments, allowing functions to be called with or without explicitly providing those arguments.

### 9. Global Variables and Variable Scope

The notebook explains the scope of variables and the distinction between variables defined outside and inside functions.

It covers:

- Global variables
- Local variables
- Variable accessibility
- Local variables taking precedence within a function
- Creating global variables from within a function

### 10. Collections and Functions

The notebook demonstrates how functions can work with collections and variable-length arguments.

##Topics include:

Packing arguments into tuples with *args
Packing keyword arguments into dictionaries with **kwargs
Passing lists and other objects to functions
Understanding how modifications to mutable objects can persist outside a function's local scope.
## Exercises and Quiz

The notebook includes practical exercises covering:

Creating a function to perform division.
Using a function to concatenate different data types.
Working with lists and tuples through functions.
Counting occurrences of a specific word in a string.
Applying functions to practical data-processing tasks.
